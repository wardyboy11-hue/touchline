# Wake-up, November 2026

This is part of the r106 preview. It is not deployed.

## What a website can do

Chrome on Android can hand the user to another app with an `intent:` link, and only after a tap. The format is documented at https://developer.chrome.com/docs/android/intents. Chrome will not open an app from a timer, and it will not open an app that does not allow browser links.

Android's clock action is `android.intent.action.SET_ALARM`, with hour and minute extras. That is documented at https://developer.android.com/reference/android/provider/AlarmClock. The stock Clock app is usually not marked as openable from the browser, so the link often does nothing. The page then tells you to copy the time. The link does not skip the clock app's own confirm screen.

iPhone has no documented URL that sets an alarm in Clock. `clock-alarm://` is not an Apple API and is not used.

A service worker, a timer, or a notification is not an alarm. None of those ring with the screen locked. A real lock-screen alarm needs an Android app using `AlarmManager.setAlarmClock`, or the person setting it in Clock. This preview does not include that app.

## What this preview does

On matchday you type a time. Nothing is created until you tap. The fixture line is Europe/London kick-off text from the fixture already on the page. The time you type is not guessed from the morning.

On Android Chrome, Try Android Clock builds the intent link. If the clock app does not open, Copy time is the fallback.

Arm preview plays a generated whistle, or a file you pick. The file stays in the page. It is not uploaded. The sound gets gradually louder inside the page only, from a quiet level to a fixed cap. It does not change the phone's volume. Stop and Snooze are on the card. Snooze and the sound both stop if you leave the page.

No Match of the Day recording is included. That theme is copyrighted and there is no free licence to bundle it. A legitimate copy was not purchased.
