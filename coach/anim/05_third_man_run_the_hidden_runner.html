Getting the voice ready

Set up

  • Three Blue players (B1, B2, B3) against one Red defender (R1).
  • A cone gate marks the halfway line, and a goal at the right hand end.
  • Run it unopposed first, then add R1.

Rules

  • B2 must play first time after the pass from B1.
  • B3 must start the run only after the ball is played, not before.
  • Offside applies from the halfway line.
  • Rotate roles every two goes.

How it starts and restarts

  • B1 starts with the ball, R1 defends in the middle
  • Ball out of play or a goal: B1 restarts with a new ball from the left.
  • The defender rotates after each attack.

Coaching points

  • Start the run when the ball is played, not before.
  • One touch from the lay off player: first time, with pace.
  • Run beyond the defender and away from his eyeline.
  • First player follows the pass to support the attack.

Progressions

  • Add a second defender, so it is 3v2.
  • Add a keeper and ask the group to score within eight seconds of the first pass.
  • Play it in a game: award a bonus point for every goal with a third man run.
